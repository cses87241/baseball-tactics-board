# 棒球戰術板 Baseball Tactics Board

互動式棒球戰術板，支援 10 種不同顏色的圓形角色標記。

類似 [tactical-board.com](https://tactical-board.com) 的棒球場佈局。

## 功能

- 棒球場圖示（草地、內野土、壘包、投手丘等）
- 10 種顏色標記（紅、黃、紫、綠、藍等）
- 點擊場地放置標記
- 拖曳移動標記
- 右鍵點擊刪除單一標記
- 一鍵清除全部

## 使用方式

1. 選擇底部工具列的顏色
2. 點擊場地上想放置的位置
3. 拖曳已放置的標記調整位置
4. 右鍵點擊標記可刪除

## 部署

此專案為純 HTML/CSS/JS，可直接開啟 `index.html` 使用。

若要啟用 GitHub Pages：

1. 前往此倉庫的 **Settings** → **Pages**
2. Source 選擇 **Deploy from a branch**
3. Branch 選擇 `main` / `/ (root)`
4. 儲存後，網站將會在 `https://cses87241.github.io/baseball-tactics-board/` 上線
